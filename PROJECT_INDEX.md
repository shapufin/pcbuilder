## Entry points

- Boot: `apps/web` `next dev`/`build`/`start` via turbo (`pnpm dev|build`).
- Payload CLI: `pnpm payload -- <cmd>` (`generate:types`,
  `generate:importmap`, `run src/seed.ts`).

## Tests

- Vitest per package (`pnpm test`, turbo); numbered cumulatively
  (#1–#401 + e2e). apps/web vitest scoped to `src/**` by
  `vitest.config.ts` (also provides the `@` alias — keep both).
- Playwright: `apps/web/e2e/{smoke,auth,builder,search-wishlist,
  cart-drawer,filter-drawer}.spec.ts`, `playwright.config.ts` — needs a
  prod build + running `next start` on :3000.

## Generated / do-not-edit

- `apps/web/src/payload-types.ts` — `pnpm payload -- generate:types`.
- `apps/web/.../importMap.js` — `pnpm payload -- generate:importmap`
  (dev server stopped) after adding admin components.
- `pnpm-lock.yaml` — pnpm only.

  regenerated by `next dev`; do not hand-edit.
